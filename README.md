# House Price Prediction

This is a Machine Learning GUI project that predicts house prices using Python and Linear Regression.

## Technologies Used
- Python
- Tkinter
- Pandas
- Scikit-learn
- Machine Learning

## Features
- GUI Application
- House price prediction
- User-friendly interface
- ML model integration

## How to Run

1. Install libraries
2. Run:
python main.py
